# Исправленная версия сайта KK Poker — что исправлено и где

Сделано в рамках аудита от 2026-11-26. Дизайн, анимации и полёт фишки в логотип — **без изменений**.
Менялись только константы размера/позиции и формула масштаба канваса. В коде каждое место помечено комментарием `FIXED-...`.

## FIXED-1. Чёрная пустота над фишкой (первый экран)

**Файл:** `index.html`, блок CSS `.stage`

**Было:**
```css
.stage{ top:clamp(160px,25svh,220px); width:440px; height:440px; transform:scale(.5) }
```
Фишка визуально 220px, сверху и снизу по ~100px пустоты (замер на 390×844: фишка 101–321px, текст с 421px).

**Стало:**
```css
.stage{ top:210px; width:440px; height:440px; transform:scale(.75) }
```
Фишка 330px (45–375px), пустота убрана.

## FIXED-2. Масштаб полёта фишки под новый размер

**Файл:** `index.html`, функция `syncChipDock()`

**Было:** `scale=.5`, `scale=.5+.22*e`, `scale=.72-.38*e`, `scale=.34+(g.scale-.34)*e`

**Стало:** `scale=.75`, `scale=.75+.33*e`, `scale=1.08-.57*e`, `scale=.51+(g.scale-.51)*e`

Посадочный масштаб (`g.scale`) **не трогали** — он считается от логотипа, поэтому фишка по-прежнему прилетает точно в логотип (проверено замером: центр совпал до пикселя).

## FIXED-3. Карты обрезаются и криво растягиваются

**Файл:** `media/tournament-motion.js`, функции `fit()` и `paint()`

**Было:**
```js
canvas.height = width * 460/900                       // всегда 900:460
ctx.scale(canvas.width/900, canvas.height/460)        // разный масштаб по X и Y
ctx.translate(0, -220)                                // жёсткая обрезка сверху
```
Блоки на телефоне другие: `.cover` 390×230, `.poster` 240×200. Итог: растяжение по вертикали +15% (обложка) и +63% (афиша), фишки справа обрезаны.

**Стало (v2, 2026-11-26):**
```js
canvas.height = реальная высота блока                 // FIXED-3a
s = canvas.width/900; ctx.scale(s, s)                 // FIXED-3b: единый масштаб
bitmap_y = s*world_y + (canvas.height/2 - 450*s)      // кадр центрирован на картах
```
Честно про историю: первая версия этого фикса (v1) содержала ошибку в формуле центрирования — на **десктопе** в высокой колонке «Ближайший турнир» она оставляла снизу незакрашенное чёрное поле и выпускала «закадровые» карты раздачи в заливку (это и был скрин из сообщения). Ошибка была в моей исправленной копии, на боевом сайте её никогда не было. В v2 формула исправлена и добавлен **FIXED-3c**: если блок заметно выше сцены 900×738, фон дорисовывается тем же фоновым полотном на весь блок, а контент клипится по кадру сцены — пустоты не остаётся и посторонние карты не вылезают.

**Проверка v2 (замеры):** мобильный 390×844 — обложка 1.696/1.696, афиша 1.200/1.200; десктоп 1280×800 — 0.791/0.789; десктоп 1055×696 (размер скрина из сообщения) — 0.647/0.648, у оригинала на том же экране 1.957/0.638 (растяжение +207%). Нижняя строка канваса на десктопе заполнена (не чёрная). Скриншоты: `poker-audit/11–15`.

## Как открыть исправленную версию

- **Через живой просмотр** (ссылка в чате) — на телефоне/компьютере, скроллить как обычно. Расписание турниров подгружается: локальный сервер `server.py` проксирует `/api/*` на боевой сайт.
- **Локально на компьютере:** в папке `poker-fixed/` запустить `python3 server.py` и открыть `http://localhost:8000` (нужен именно сервер, потому что сайт подгружает файлы из папки `media/`, а `server.py` заодно подтягивает живое расписание).
- **На хостинге:** залить папку `poker-fixed/` целиком — все правки уже внутри `index.html` и `media/tournament-motion.js`.
- Совсем без сервера: открыть `index.html` двойным кликом — всё покажется, кроме раздела «Турниры недели» (там живые данные по `/api/public`; вместо них будет надпись «Получаем данные клуба»).

Вверху страницы — жёлтая плашка с перечнем исправлений (FIXED-1/2/3); при скролле она уезжает вместе со страницей и не мешает смотреть сайт.

## FIXED-GH. Адаптация под GitHub Pages (эта сборка)

Три правки чисто для хостинга на `cnizroman.github.io/KK/`, логику фиксов не меняют:

- **FIXED-GH1** (`media/club-live.js`): живой запрос `fetch('/api/public')` заменён на снимок данных `api/public.json` — на GitHub Pages нет серверного API. Расписание показывается реальное, но зафиксированное на момент сборки (на боевом сайте оно живое).
- **FIXED-GH2** (`media/tournament-motion.js`): распознавание сцены анимации отвязано от начала пути — иначе в подпапке `/KK/` анимации карт не включались.
- **Пути**: в `index.html` все ссылки `/media/...` сделаны относительными (`media/...`) — абсолютные пути и были причиной «косяков» первой заливки: GitHub Pages отдаёт сайт из подпапки `/KK/`, и все стили/шрифты/скрипты 404-или незагружались.
- Добавлен файл `.nojekyll` — чтобы GitHub Pages не обрабатывал файлы своим генератором.

Проверка: главная, «Ближайший турнир», «Турниры недели» — стили, шрифты, анимации и расписание на месте; сетевых 404 нет.
